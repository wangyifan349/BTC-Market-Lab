## ✨ Features

- 🌐 **Three data sources** — switch between Binance, OKX and CoinGecko with one click.
- ⏱️ **Six timeframes** — 1 hour, 4 hours, daily, weekly, monthly and yearly
  (yearly is generated by resampling monthly data).
- 🕯️ **Interactive chart** — candlesticks (or a close-price line in log mode),
  volume sub-chart, crosshair with per-candle OHLC details, grid toggle.
- 📊 **NumPy statistics report** — prices, returns, drawdowns, distribution
  shape and trend indicators, printed to the console **and** shown as UI cards.
- 📉 **Polynomial regression forecast** — adjustable degree (1–24), extrapolation
  horizon, trailing fit window, optional **log-space fitting** for BTC's
  exponential long-term growth, plus an R² / RMSE / σ quality panel and a
  ±1.96σ confidence band on the chart.
- 🧮 **NumPy expression console** — run any NumPy expression against the loaded
  data inside a safe sandbox, with a gallery of one-click quick expressions.
- 🔁 **Self-healing networking** — tries `HTTP proxy 127.0.0.1:10808 →
  HTTP proxy 10809 → SOCKS5 proxy 10808 → direct connection`, remembers the
  winner, and lets you re-probe at any time.

## 🚀 Quick Start

```bash
cd en
python BTC_Market_Lab.py
```

> 💡 **Tip:** launch from a terminal / command prompt, **not from IDLE** — IDLE's
> pseudo-stdout can garble some console output.

On startup the app automatically downloads ~2,000 daily candles for `BTCUSDT`,
computes the statistics report, and runs a forecast. Everything is also printed
to the terminal you launched it from.

## 🖱️ Usage Guide

### 🏠 Left: Chart panel

| Control          | What it does                                              |
|------------------|-----------------------------------------------------------|
| 🕯️ Candles / Log Y | Switch between candlesticks and a log-scaled close line |
| 🕸️ Grid           | Toggle the chart grid                                     |
| 🎯 Crosshair      | Toggle the mouse crosshair (hover shows OHLC + volume)    |

### 📑 Right: Four tabs

**1️⃣ Market** — pick the data source (Binance / OKX / CoinGecko), timeframe and
pair (default `BTCUSDT`), then hit 🟠 **Refresh Data**. Use **Retest Network**
to re-probe connectivity. Four quick cards show last price, period change,
annualized volatility and bar count.

**2️⃣ Forecast** — polynomial regression settings:

| Parameter          | Meaning                                                        |
|--------------------|----------------------------------------------------------------|
| 🎚️ **Degree n**  | Highest polynomial power (1–24, default 5)                     |
| 🔮 **Extrapolate** | How many future bars to project (0–500, default 30)            |
| 🪟 **Fit Window**  | `0` = use all data; otherwise fit only the last N bars         |
| 📐 **Log-space fit** | Fit `ln(close)` instead of `close` *(recommended for BTC)*   |
| 🔄 **Auto re-forecast** | Re-run automatically whenever a parameter changes          |

The **Fit Quality** panel lists R², adjusted R², RMSE, MAE, MAPE, residual σ,
sample count and the next-period forecast (colored by sign 🟢/🔴).

**3️⃣ Stats** — 16 key NumPy statistics as cards, plus the **Full Report** text
(*Recalc & Print* → console, *Copy Report* → clipboard).

**4️⃣ NumPy** — a sandboxed expression console:

```text
Available variables:  np / close / open / high / low / volume / ret / logret / idx / n / ts
```

For example `np.percentile(close, [25, 50, 75])` or
`np.corrcoef(ret[:-1], ret[1:])[0,1]`. Click any **Quick Expressions** chip to
run it instantly.

## 📊 Statistics (all computed with NumPy)

- 🪙 **Price** — `np.mean` · `np.median` · `np.std` · `np.var` · `np.min/max` ·
  `np.ptp` · `np.percentile` (5/25/50/75/95) · IQR
- 💹 **Returns** — total return · mean/median per-period · per-period volatility ·
  best/worst period · up/down/flat counts & win rate · longest up/down streak ·
  annualized geometric return · annualized volatility · Sharpe (rf=0) ·
  max drawdown · Calmar ratio · cumulative net value · `np.quantile` (0.05/0.5/0.95)
- 🎲 **Distribution shape** — log-return mean/std · skewness · excess kurtosis ·
  `np.corrcoef` price↔time · price↔volume · return autocorrelation
- 📈 **Trend / indicators** — `np.polyfit` log-price trend (annualized) ·
  `np.gradient` latest change · SMA20/50/200 · EMA12/26 · MACD/Signal · RSI(14) ·
  BOLL20 (±2σ) · average candle range · volume sum/mean/median
- 🔮 **Forecast** — least-squares polynomial `y = aₙxⁿ + … + a₀` with x normalized
  to [-1, 1] (numerically stable even at high degrees), optional log-space,
  extrapolated horizon and a ±1.96σ confidence band.

## 🌐 Networking

Requests are tried **in order**:

1. 🌐 `HTTP proxy 127.0.0.1:10808`
2. 🌐 `HTTP proxy 127.0.0.1:10809`
3. 🔌 `SOCKS5 proxy 127.0.0.1:10808`
4. ⚡ Direct connection (no proxy)

As soon as one succeeds it is **remembered and reused** (the status bar shows
the active strategy). If all fail you'll see **"Network: All strategies failed"**
— click **Retest Network** to re-probe.

To change the proxy address / port, edit `PROXY_HOST` / `PROXY_PORT` at the top
of the script.

## 🛠️ Troubleshooting

| Problem                      | Solution                                                              |
|------------------------------|-----------------------------------------------------------------------|
| 🔴 **"Network: Not connected"** | Start your proxy (v2rayN / Clash...) and click **Retest Network**. Or edit `PROXY_HOST` / `PROXY_PORT`. |
| ⚠️ **"Data fetch failed"**     | Switch to another source (OKX / CoinGecko) or retry later — APIs can rate-limit. |
| ❓ **`?` characters in console** | The app prints `R²` / `σ` safely; under a GBK terminal a few glyphs show as `?` — output stays readable. |
| ⏳ **No data on startup**       | Startup fetch begins ~80 ms after launch; watch the status bar.       |
| 🌐 **Want a different language?** | Chinese version → `../zh/` folder · Japanese docs → `../jp/README.md`. |
