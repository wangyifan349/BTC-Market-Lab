# 📈 BTC マーケットラボ（BTC Market Lab）

> **PyQt6 + pyqtgraph + NumPy** で作られたビットコインの**統計分析 · 予測 · バックテスト**用デスクトップツール（v2.2 · ダークテーマ）。

```text
📦 このフォルダ（日本語ドキュメント）: jp/
🌍 中国語版アプリ:  ../zh/ フォルダ（実行ファイル名は中国語）
🌍 英語版アプリ:    ../en/BTC_Market_Lab.py
```

> [!CAUTION]
> **教育・研究目的のみ。本ツールは投資助言ではありません。** 暗号通貨市場は非常に変動が大きく、投資元本の損失が発生する可能性があります。予測曲線はあくまで多項式外挿であり、**将来の値動きの保証ではありません**。

## ✨ 主な機能

- 🌐 **3 つのデータソース** —— Binance / OKX / CoinGecko をワンクリックで切替。
- ⏱️ **6 つの時間足** —— 1時間・4時間・日足・週足・月足・年足（年足は月足からリサンプリング生成）。
- 🕯️ **インタラクティブなチャート** —— ローソク足（または対数スケールの終値ライン）、出来高サブチャート、十字カーソルで各足の詳細表示、グリッド切替。
- 📊 **NumPy 統計レポート** —— 価格・リターン・ドローダウン・分布形状・トレンド指標を、コンソールと UI カードの両方に出力。
- 📉 **多項式回帰予測** —— 次数（1–24）・外挿期間・フィッティング窓を調整可能。BTC の長期指数成長に合わせた**対数空間フィット**対応。R² / RMSE / σ の品質パネルと ±1.96σ の信頼帯を描画。
- 🧮 **NumPy 式コンソール** —— サンドボックス内でデータに任意の NumPy 式を実行可能。ワンクリックの「クイック式」も用意。
- 🔁 **自己修復型ネットワーク** —— `HTTP プロキシ 127.0.0.1:10808 → HTTP プロキシ 10809 → SOCKS5 プロキシ 10808 → 直接接続` の順に試行。成功した経路を自動で記憶し、いつでも再探索できます。

## 🖱️ 使い方

### 🏠 左側：チャートエリア

| 操作             | 説明                                                     |
|------------------|----------------------------------------------------------|
| 🕯️ ローソク足 / 対数Y | ローソク足チャートと対数スケール終値ラインを切替        |
| 🕸️ グリッド       | チャートのグリッド表示切替                               |
| 🎯 十字カーソル   | マウス十字線を切替（ホバーで OHLC + 出来高を表示）        |

### 📑 右側：4 つのタブ

**1️⃣ Market（マーケット）** —— データソース（Binance / OKX / CoinGecko）、時間足、銘柄（デフォルト `BTCUSDT`）を選択し、🟠 **Refresh Data** で取得。**Retest Network** で接続を再探索。最上部の 4 枚のカードに最新価格・区間変動・年率ボラティリティ・本数を表示。

**2️⃣ Forecast（予測）** —— 多項式回帰の設定：

| パラメータ          | 意味                                                          |
|---------------------|---------------------------------------------------------------|
| 🎚️ **Degree n**   | 多項式の最高次数（1–24、デフォルト 5）                          |
| 🔮 **Extrapolate** | 未来へ何本先まで予測するか（0–500、デフォルト 30）              |
| 🪟 **Fit Window**  | `0` で全データを使用。それ以外は直近 N 本のみでフィット        |
| 📐 **Log-space fit** | `close` の代わりに `ln(close)` をフィット（BTC 長期間の推奨） |
| 🔄 **Auto re-forecast** | パラメータ変更時に自動で再予測                             |

**Fit Quality** パネルに R²・調整済み R²・RMSE・MAE・MAPE・残差 σ・サンプル数・翌期予測値（増減で色分け 🟢/🔴）を表示します。

**3️⃣ Stats（統計）** —— 主要統計カード 16 枚と、全計算過程の **Full Report**（*Recalc & Print* でコンソール出力、*Copy Report* でクリップボードへ）。

**4️⃣ NumPy** —— サンドボックス式コンソール：

```text
利用可能な変数:  np / close / open / high / low / volume / ret / logret / idx / n / ts
```

例：`np.percentile(close, [25, 50, 75])` や `np.corrcoef(ret[:-1], ret[1:])[0,1]`。**Quick Expressions** のボタンをクリックすれば即実行できます。

## 📊 計算される統計指標（すべて NumPy）

- 🪙 **価格** —— `np.mean` 平均 · `np.median` 中央値 · `np.std` 標準偏差 · `np.var` 分散 · `np.min/max` 最安/最高 · `np.ptp` レンジ · `np.percentile`（5/25/50/75/95）· IQR
- 💹 **リターン** —— 全区間リターン · 1期間あたり平均/中央リターン · 期間ボラティリティ · 最良/最悪期間 · 上昇/下落/横ばい本数と勝率 · 連続上昇/下落の最長 · 年率リターン（幾何平均）· 年率ボラティリティ · シャープレシオ（無リスク=0）· 最大ドローダウン · カルマーレシオ · 累積資産曲線 · `np.quantile`（0.05/0.5/0.95）
- 🎲 **分布形状** —— 対数リターンの平均/標準偏差 · 歪度 · 超過尖度 · `np.corrcoef` 価格↔時間 · 価格↔出来高 · リターンの自己相関
- 📈 **トレンド / 指標** —— `np.polyfit` 対数価格トレンド（年率換算）· `np.gradient` 直近の限界変化 · SMA20/50/200 · EMA12/26 · MACD/Signal · RSI(14) · BOLL20（±2σ）· 平均レンジ · 出来高 sum/mean/median
- 🔮 **予測** —— 最小二乗多項式フィット `y = aₙxⁿ + … + a₀`。x を [-1, 1] に正規化して高次でも数値的に安定させ、任意の対数空間、未来への外挿、±1.96σ の信頼帯を描画します。

## 🌐 ネットワーク戦略

リクエストは次の順に試行します：

1. 🌐 `HTTP プロキシ 127.0.0.1:10808`
2. 🌐 `HTTP プロキシ 127.0.0.1:10809`
3. 🔌 `SOCKS5 プロキシ 127.0.0.1:10808`
4. ⚡ 直接接続（プロキシなし）

成功した経路は**記憶され、以降のリクエストで優先利用**されます（ステータスバーに表示）。すべて失敗した場合は **「Network: All strategies failed」** と表示されるので、**Retest Network** で再探索してください。

プロキシのアドレス・ポートを変更する場合は、スクリプト冒頭の `PROXY_HOST` / `PROXY_PORT` を編集します。

## 🛠️ トラブルシューティング

| 問題                          | 対処方法                                                              |
|-------------------------------|-----------------------------------------------------------------------|
| 🔴 **「Network: Not connected」** | プロキシ（v2rayN / Clash 等）を起動し **Retest Network** を押す。または `PROXY_HOST` / `PROXY_PORT` を編集。 |
| ⚠️ **「Data fetch failed」**     | 別のデータソース（OKX / CoinGecko）へ切替えるか、時間をおいて再試行（API のレート制限）。 |
| ❓ **コンソールが `?` になる**    | `R²` / `σ` は安全に処理済み。GBK 環境では一部 `?` になることがありますが、表示は読み取れます。 |
| ⏳ **起動してもデータが出ない** | 起動後約 80ms で自動取得が始まります。ステータスバーの進捗をご確認ください。 |
| 🌐 **言語・バージョンは？**      | 中国語 → `../zh/` フォルダ · 英語 → `../en/BTC_Market_Lab.py`。       |
