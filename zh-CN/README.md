```text
📦 本目录（中文版）：预测工具.py
🌍 英文版请见：../en/BTC_Market_Lab.py
```

## ✨ 功能亮点

- 🌐 **三数据源** —— Binance / OKX / CoinGecko 一键切换。
- ⏱️ **六种周期** —— 1 小时、4 小时、日线、周线、月线、年线（年线由月线重采样生成）。
- 🕯️ **交互图表** —— K 线蜡烛（或对数坐标下的收盘价折线）、成交量副图、十字光标逐一查看每根 K 线明细、网格开关。
- 📊 **NumPy 统计报告** —— 价格、收益、回撤、分布形态、趋势指标等，既打印到控制台，也上屏为 UI 卡片。
- 📉 **多项式回归预测** —— 可调阶数（1–24）、外推期数、拟合窗口；支持**对数空间拟合**以贴合 BTC 的长期指数增长；附 R² / RMSE / σ 质量面板与图表上的 ±1.96σ 置信带。
- 🧮 **NumPy 表达式控制台** —— 在安全沙箱内对已加载数据执行任意 NumPy 表达式，内置一键快捷计算。
- 🔁 **自愈式网络** —— 依次尝试 `HTTP 代理 127.0.0.1:10808 → HTTP 代理 10809 → SOCKS5 代理 10808 → 直连`，谁通就用谁、并自动记住，随时可重新探测。

## 🖱️ 使用说明

### 🏠 左侧：图表区

| 控件             | 作用                                         |
|------------------|----------------------------------------------|
| 🕯️ K线蜡烛 / 对数坐标 | 在蜡烛图与对数坐标收盘价折线之间切换       |
| 🕸️ 网格          | 开关图表网格                                 |
| 🎯 十字光标      | 开关鼠标十字光标（悬停查看 OHLC + 成交量）   |

### 📑 右侧：四个标签页

**1️⃣ 行情** —— 选择数据源（Binance / OKX / CoinGecko）、周期与币对（默认 `BTCUSDT`），点 🟠 **刷新数据** 加载；**重测网络** 可随时重新探测连通性。顶部四张小卡片展示最新价、区间涨跌、年化波动与样本根数。

**2️⃣ 预测** —— 多项式回归参数：

| 参数              | 作用                                                     |
|-------------------|----------------------------------------------------------|
| 🎚️ **最高次 n**  | 多项式最高次幂（1–24，默认 5）                            |
| 🔮 **外推长度**   | 向外预测多少根（0–500，默认 30）                          |
| 🪟 **拟合窗口**   | `0` 表示使用全部数据；否则只拟合最近 N 根                 |
| 📐 **对数空间拟合** | 拟合 `ln(close)` 而非 `close`（BTC 长周期推荐）          |
| 🔄 **自动重新预测** | 参数一改就自动重跑                                       |

**拟合质量**面板显示 R²、调整后 R²、RMSE、MAE、MAPE、残差 σ、样本数与下一期预测值（按涨跌分色 🟢/🔴）。

**3️⃣ 统计** —— 16 项关键 NumPy 统计卡片，外加**完整计算报告**全文（*重新计算并打印* 输出到控制台，*复制报告* 一键复制）。

**4️⃣ NumPy** —— 安全沙箱表达式控制台：

```text
可用变量：np / close / open / high / low / volume / ret / logret / idx / n / ts
```

例如 `np.percentile(close, [25, 50, 75])` 或 `np.corrcoef(ret[:-1], ret[1:])[0,1]`。点任意**快捷计算**按钮直接运行。

## 📊 统计指标一览（全部由 NumPy 计算）

- 🪙 **价格** —— `np.mean` 均价 · `np.median` 中位价 · `np.std` 标准差 · `np.var` 方差 · `np.min/max` 最低/最高 · `np.ptp` 极差 · `np.percentile`（5/25/50/75/95）· IQR
- 💹 **收益** —— 区间涨跌幅 · 平均/中位单期涨跌 · 单期波动 · 最大单期涨幅/跌幅 · 上涨/下跌/平盘数与上涨占比 · 最长连涨/连跌 · 年化收益（几何）· 年化波动率 · 夏普比率（无风险=0）· 最大回撤 · 卡玛比率 · 累计净值 · `np.quantile`（0.05/0.5/0.95）
- 🎲 **分布形态** —— 对数收益均值/标准差 · 偏度 · 超额峰度 · `np.corrcoef` 价格↔时间 · 价格↔成交量 · 收益一阶自相关
- 📈 **趋势 / 指标** —— `np.polyfit` 对数价格趋势（年化）· `np.gradient` 最新边际变化 · SMA20/50/200 · EMA12/26 · MACD/Signal · RSI(14) · BOLL20（±2σ）· 平均振幅 · 成交量 sum/mean/median
- 🔮 **预测** —— 最小二乘多项式拟合 `y = aₙxⁿ + … + a₀`，x 先归一化到 [-1, 1]（高阶拟合数值稳定），可选对数空间，外推至未来，并绘制 ±1.96σ 置信带。

## 🌐 网络策略

请求依次尝试：

1. 🌐 `HTTP 代理 127.0.0.1:10808`
2. 🌐 `HTTP 代理 127.0.0.1:10809`
3. 🔌 `SOCKS5 代理 127.0.0.1:10808`
4. ⚡ 直连（无代理）

一旦某个策略成功，它会被**记住并在后续请求中优先复用**（状态栏会显示当前策略）。若全部失败，状态栏显示 **「网络：全部策略失败」**，点 **重测网络** 即可重新探测。

如需修改代理地址/端口，请编辑脚本顶部的 `PROXY_HOST` / `PROXY_PORT`。

## 🛠️ 常见问题

| 问题                     | 解决办法                                                         |
|--------------------------|------------------------------------------------------------------|
| 🔴 **「网络：未连接」**  | 启动代理（v2rayN / Clash 等）并点**重测网络**；或修改 `PROXY_HOST` / `PROXY_PORT`。 |
| ⚠️ **「数据获取失败」**  | 换一个数据源（OKX / CoinGecko）或稍后重试 —— 接口偶尔会限流。       |
| ❓ **控制台显示 `?`**    | 程序已安全处理 `R²` / `σ`；GBK 终端下个别字符显示为 `?` 属正常，不影响阅读。 |
| ⏳ **启动后好像没数据**   | 启动后约 80ms 会自动开始拉取，观察状态栏进度即可。                |
| 🌐 **想要英文版？**       | 英文版见 `../en/BTC_Market_Lab.py`。                               |
